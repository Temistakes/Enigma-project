## Для разработчика на pip

### 1. Установка зависимостей
```bash
# Активировать своё venv, затем:
pip install -r requirements.txt       # только проект
pip install -r requirements-dev.txt   # проект + ruff + ty

### 2. Использование Ruff (Линтер и форматтер)

# Проверить код на ошибки стиля и логики
ruff check .

# Автоматически исправить простые ошибки и отсортировать импорты
ruff check --fix .
# Отформатировать весь код проекта
ruff format .

### 3. Использование ty (Проверка типов от Astral)

# Проверить типы во всём проекте
ty check

│ Примечание: Если команды ruff или ty не находятся напрямую в терминале, запускай их
│ через модуль Python в активном venv:
│ python -m ruff check .
│ python -m ty check


### Что МОЖНО и НУЖНО коммитить в hotfix:

1. Критические баги (P0 / Blocker):
    • Сервер падает с ошибкой 500 Internal Server Error на ключевых действиях.
    • Сломалась авторизация/регистрация — пользователи не могут войти.
    • Падают платежи или ломается оформление заказа.
2. Дыры в безопасности (Security Patches):
    • Обнаружена уязвимость (утечка токенов, SQL-инъекция, открытый доступ к чужим данным).
    • Срочное обновление версии библиотеки, в которой нашли критический эксплойт.
3. Падение интеграций со сторонними сервисами:
    • Сторонний сервис (банк, Telegram API, почтовый шлюз) внезапно сменил формат ответа, и бэкенд перестал его понимать.
